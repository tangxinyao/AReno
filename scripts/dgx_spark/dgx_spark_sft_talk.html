1 · This is a Mac Mini

tiny runs on it

Ling-3.0-tiny is an open-source MoE model from inclusionAI. It has the inference cost of 1.3B and the knowledge of 7.9B, and it runs on a single Mac Mini.

Active / total parameters
1.3B/ 7.9B

7.9B total sets how capable it is: the knowledge lives in the experts. 1.3B active sets the inference cost: each forward pass computes only about one sixth of it.

Why an LLM

The flash-Fin session ran to completion, so its structure looks normal. Only an LLM reading the content can tell that the answer was wrong.

A wrong answer contains no correct answer. Knowledge injection needs reference answers, so the dataset is built from public material, and every row cites its sources.

bad_cases.jsonl tells us which knowledge the model is missing. We don't train on the logs this round; the bad cases can later serve as the rejected side for DPO / GSPO.

5 · LoRA SFT

Teaching it 21 facts takes one command

areno train --algo sft --ckpt inclusionai/ling-3.0-tiny --model-hub modelscope \
  --dataset-path examples/sft/ling_flash_fin/data/train.jsonl \
  --dataset-loader-fn examples/sft/ling_flash_fin/dataset_loader.py \
  --batch-size 2 --epochs 10 \
  --max-prompt-tokens 128 --max-new-tokens 512 \
  --disable-thinking --attn-backend flash \
  --activation-checkpointing --adam-4bit \
  --lr 1e-4 --min-lr 1e-5 --lora-rank 16 \
  --save-path ~/fin_sft_lora --save-interval 50
DGX Spark · repo root · single GPUplus --world-size 1 --tp-size 1 --mini-bs 1; full command in the runbook, section 5
Where the step count comes from
99rows÷ 2batch= 50steps / epoch
×10epochs= 500steps · 10 checkpoints
Three hard rules
  1. No final checkpointSaves happen only when the step is a multiple of 50. Nothing extra is saved at the end.
  2. Use --disable-thinking for both training and servingOtherwise the template renders a thinking block the model never saw in training.
  3. New data or hyperparameters means a new --save-pathOld and new checkpoints in one directory are easy to mix up during a demo.

7 · A good start

Start with one wrong answer, and go one step at a time

Today was the simplest kind of model improvement: a new model ships, our model doesn't know it, we find the wrong answer in the logs, build a dataset, run LoRA SFT, and it's fixed on the spot.

Today
Knowledge injection

99 Q&A pairs, one adapter, about ten minutes of training, and a before/after you can see at a glance.

Next
Office and industry domains

These need a much richer eval set and mocked environments, to make sure the model actually got better instead of memorizing a few hundred sentences.

Why this pairing
AReno + tiny

The model is small enough to retrain locally, again and again. Training and serving share one CLI. Real usage → logs → dataset is already a working path.
